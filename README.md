# MKN-10

Pomůcka pro ambulanci praktického lékaře: rychlé vyhledání kódu diagnózy podle české MKN-10.

**Online:** https://xdenny.github.io/mkn10-cheatsheet/

- vyhledávání v celém číselníku MKN-10-CZ (s diakritikou i bez, podle kódu i názvu, toleruje překlepy)
- oblíbené diagnózy, naposledy použité, seznam častých diagnóz v ambulanci
- vložený text se zápisem (anamnéza, diagnózy) se rozdělí na jednotlivé diagnózy a ke každé se najdou nejpodobnější kódy
- funguje offline, nic se neodesílá, stačí otevřít `index.html` v prohlížeči

Návrhy kódů jsou jen pomůcka založená na porovnání slov, kód vždy zkontrolujte.
